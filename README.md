THE HMAC &mdash; a member of [[kryptos]]. HMAC(K,m)=H((K&oplus;opad)&#8214;H((K&oplus;ipad)&#8214;m)) nests a hash twice around a secret key, so only a key-holder produces the valid tag &mdash; a bare hash can&rsquo;t, and it resists length-extension. Authenticates API requests, JWTs, cookies, and TLS records. &#9670; LIT: a fail-loud check throws unless the tag is deterministic yet changes under any key or message edit. &#9650; AMBER: shown with a toy hash (real: SHA-256); gives authenticity not confidentiality, shared-key not public.
